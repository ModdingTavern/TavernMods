Manifest Builder

Fill this in to make the manifest for a new mod or a new version, then open the pull request or download the file. Rules: SUBMITTING.md. Nothing you enter leaves your browser until you open the pull request.

Mod

The id is your GitHub owner.repo; every build must be a release asset of that repo. Updating? Fill in the owner and repo and load what's published, then change the version, links and hashes.

Joining a server

If unsure, keep the first: parity_required: true.

Scenes

Leave all unticked if the mod works in every scene. Tick only the ones it works in otherwise.

Builds

One entry per file you ship: a .dll, or a .zip with the mod's DLL at its root. One file can serve several targets, but each target can have only one build. Hash a file here, or leave the hash empty and run python tools/modindex.py fill-hashes on the downloaded manifest.

Dependencies

Other mods this one needs, by id and minimum version. Shared DLLs belong under a build's libraries instead.

Screenshots

Optional, up to 4, shown on the mod page. A release asset of your repo, or a raw.githubusercontent.com link pinned to a commit; .png, .jpg, .webp or .gif.
